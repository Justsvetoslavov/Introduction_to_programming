# Условни конструкции
Конструкция, която дава възможност да се изпълни (или не) една или друга последователности от действия (оператори), в зависимост от някакво условие, се нарича **условна**.

## if - else
```c++
if (<условие>)
{
  <действие>
}
```

### Семантика
- `if` (ако) – запазена дума в езика C++.
- `else` (иначе) - запазена дума в езика C++.
- `else if` (или ако) - комбинация от else и if, която позволява последователна проверка на няколко условия. Това не е отделна запазена дума.
- `<условие>` – израз, чиято стойност се преобразува до булева стойност (true или false).
- `<действие>` – един оператор или последователност от оператори, които се изпълняват, когато условието е изпълнено.

```c++
if (<условие>)
{
  // изпълнява се, ако условието е истина
}
else // не е задължителен компонент
{
  // изпълнява се, ако условието е лъжа
}
```

Пресмята се стойността на булевия израз, обуславящ условието.
Ако резултатът е `true`, изпълнява се `<действие>`.
В противен случай `<действие>` **НЕ** се изпълнява.

**Важно:**
- Ако тялото на if или else съдържа само един оператор, фигурните скоби {} не са задължителни. Препоръчително е да се използват за по-добра четимост и за избягване на грешки.
- Променлива, декларирана в блок {}, е достъпна само в рамките на съответния обхват (scope), в който е декларирана, и във вложените в него обхвати.

```c++
int x = 10;

if (x > 5)
{
    cout << "x е по-голямо от 5" << endl;
}
else
{
    cout << "x е по-малко или равно на 5" << endl;
}
```

## if - else if - else
```c++
if (<condition1>)
{
    // изпълнява се, ако <condition1> е истина
}
else if (<condition2>)
{
    // изпълнява се, ако <condition1> е лъжа и <condition2> е истина
}
else if (<condition3>)
{
    // изпълнява се, ако <condition1> и <condition2> са лъжа и <condition3> е истина
}
// ... може да има произволен брой else if
else if (<conditionK>)
{
    // изпълнява се, ако всички предходни условия са лъжа и <conditionK> е истина
}
else // не е задължителен компонент
{
    // изпълнява се, ако всички горни условия са лъжа
}
```

> **Важно:** Условията се проверяват последователно отгоре надолу. Щом едно условие е изпълнено, останалите **НЕ** се проверяват.

int score = 85;

{

### Разлика между няколко if конструкции и if-else if
При използване на няколко независими `if` конструкции всяко условие се проверява самостоятелно. Възможно е да се изпълнят няколко от тях.   
При използване на `if-else if-else` се изпълнява най-много едно от телата на конструкцията – това на първото условие, което е истина. Ако няма такова условие и е зададен `else`, се изпълнява неговото тяло.

```c++
int x = 10;

// Независими if конструкции
if (x > 0)
{
    cout << "Positive" << endl;
}

if (x > 5)
{
    cout << "Greater than 5" << endl;
}

int y = 10;

// Верига if-else if
if (y > 0)
{
    cout << "Positive" << endl;
}
else if (y > 5)
{
    cout << "Greater than 5" << endl;
}
```

## Switch statement

```c++
switch(<израз>)
{
  case <стойност1> : <действия>;
  break;
  case <стойност2> : <действия>
  break;
  case <стойностN> : <действия>;
  break;
  default: <действия>;
}
```

### Семантика
- `switch` (ключ) - запазена дума.
- `case` (случай, вариант) - запазена дума.
- `<израз>` 
    - израз от целочислен или изброим тип (enum).
        - Например: `int`, `char` или `bool`.
        - tипът на израза може да бъде подложен на стандартните целочислени преобразувания.
    - изрази от тип `float` и `double` не могат директно да се използват като управляващ израз на `switch`.
- `<стойност1>`, `<стойност2>`, ... `<стойностN>` – **константни** изрази с различни стойности, съвместими с типа на `<израз>`.
- `default` (по подразбиране) – незадължителен; изпълнява се, ако нито един `case` не съвпада.
- `break` – прекратява изпълнението на `switch` и излиза от него.
    - `break` прекратява изпълнението на най-близкия обхващащ цикъл (`for`, `while`, `do-while`) или конструкция `switch`.
    - в `switch`, ако липсва `break`, изпълнението продължава със следващите оператори, включително тези след следващите case етикети. Това поведение се нарича fall-through.
    - fall-through може да се използва умишлено, когато няколко case етикета трябва да водят до едно и също действие.
```c++
switch (<израз>)
{
    case value1:
        // код за value1
        break;
    
    case value2:
        // код за value2
        break;
    
    case value3:
        // код за value3
        break;
    
    default:
        // код, ако няма съвпадение
        break; // break в default е опционален, но добра практика
}
```

**Пример:**
```c++
int day = 3;

switch (day)
{
    case 1:
        cout << "Понеделник" << endl;
        break;
    
    case 2:
        cout << "Вторник" << endl;
        break;
    
    case 3:
        cout << "Сряда" << endl;
        break;
    
    case 4:
        cout << "Четвъртък" << endl;
        break;
    
    case 5:
        cout << "Петък" << endl;
        break;
    
    case 6:
    case 7:
        cout << "Уикенд" << endl; // fall-through за case 6 и 7
        break;
    
    default:
        cout << "Невалиден ден" << endl;
        break;
}
// Изход: Сряда
```

## Тернарен оператор

Тернарният оператор е съкратена форма на `if-else` конструкция, която връща стойност.

### Синтаксис
```c++
<условие> ? <израз1> : <израз2>
```

### Семантика
- Ако <условие> е истина (true), се оценява <израз1>.
- Ако <условие> е лъжа (false), се оценява <израз2>.
- Резултатът от целия израз е стойността на избрания израз. Двата израза трябва да са съвместими според правилата за типовете в C++.

> Важно: Оценява се само един от двата израза – този, който съответства на резултата от условието.

<div style="text-align: left;">
<img src="00-images/Ternary-operator.jpg" style="max-width: 60%; height: auto;">
</div>

**Примери:**
```c++
// Намиране на по-голямото от две числа
int a = 10, b = 20;
int max = (a > b) ? a : b; // max = 20

// Проверка за четност
int num = 7;
string result = (num % 2 == 0) ? "четно" : "нечетно"; // result = "нечетно"

// Използване в cout
int age = 16;
cout << "Вие сте " << ((age >= 18) ? "пълнолетен" : "непълнолетен") << endl;

// Вложени тернарни оператори (НЕ е препоръчително за четимост)
int x = 5;
string type = (x > 0) ? "положително" : (x < 0) ? "отрицателно" : "нула";
```

**Важно:**
- Използвайте тернарен оператор за **прости** условия.
- За сложна логика предпочитайте `if-else` за по-добра четимост.
- И двата израза (`<израз1>` и `<израз2>`) трябва да са от съвместими типове.

- Вход: 120, Изход: Between 100 and 200
- Вход: 250, Изход: Greater than 200

## Speed check
Да се напише програма, която въвежда скорост (десетично число) и отпечатва информация за скоростта.
- При скорост до 10 (включително) отпечатайте “slow”.
- При скорост над 10 и до 50 отпечатайте “average”.
- При скорост над 50 и до 150 отпечатайте “fast”.
- При скорост над 150 и до 1000 отпечатайте “ultra fast”.
- При по-висока скорост отпечатайте “extremely fast”
    
### Примери
- Вход: 8, Изход: slow <br />
- Вход: 49.5, Изход: average <br />
- Вход: 126, Изход: fast <br />
- Вход: 3500, Изход: extremely fast <br />
