## Задача 3:
```c++
#include <iostream>

void main() {
	unsigned int x = 0x11335577;
	unsigned char* ptr = (unsigned char*)&x;
	++*ptr;
	++*(ptr + 1);
	++ptr[2];
	++3[ptr];
	std::cout << std::hex << "0x" << x;
}

// Additional personal question: Does endiness matter?
```

## Въпрос 1 (държавен 2023 година)
Нека a и b са променливи от тип char. Да се посочи какъв е проблемът в дадения по-долу фрагмент.
char result = a + b; Да се посочи възможен начин, чрез който може да се реши този проблем.
